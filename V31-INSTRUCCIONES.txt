# Finanzas App V31 — Corrección real de invitaciones

Esta versión corrige el problema mostrado como:
“No se pudo comprobar invitaciones existentes.”

La causa estaba en la Edge Function: V30 todavía incluía la comprobación
opcional de invitaciones duplicadas. V31 elimina completamente esa consulta.

Flujo V31:
1. Comprueba la sesión del usuario.
2. Comprueba que sea propietario del espacio.
3. Genera un token seguro en el servidor.
4. Crea la invitación.
5. Envía el correo mediante Resend.

NO se elimina RLS.
NO se expone RESEND_API_KEY.
NO se requiere crear manualmente al usuario invitado.

## IMPORTANTE

En esta versión SÍ debes actualizar la Edge Function `send-invitation`.

### Supabase
1. Supabase → Edge Functions → `send-invitation`
2. Code
3. Reemplaza el contenido de `index.ts` por el incluido en:
   `supabase/functions/send-invitation/index.ts`
4. Deploy updates.
5. Confirma que “Verify JWT with legacy secret” permanezca OFF, como ya lo tenías.

### GitHub
El frontend también viene actualizado a V31:
- app.js
- index.html
- sw.js

Sube esos archivos a GitHub y haz commit.

Después:
- Ctrl+F5
- abre Invitar integrante
- prueba nuevamente el correo.

Si aparece otro mensaje, ese ya será el error real de la siguiente etapa
(insertar invitación o enviar por Resend), y podremos corregirlo con precisión.
