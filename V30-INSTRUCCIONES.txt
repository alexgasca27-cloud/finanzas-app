# Finanzas App V30 — Invitaciones

Esta versión corrige el flujo del frontend para que la invitación se envíe
directamente mediante la Edge Function `send-invitation`.

IMPORTANTE:
- No hace ninguna consulta directa a `workspace_invitations` desde el navegador.
- No requiere que el invitado tenga una cuenta previa.
- La persona invitada recibe un correo y después inicia sesión con Google.
- La API de Resend permanece en Supabase Secrets.
- El service worker y el query-string de app.js están actualizados a V30 para
  evitar que la PWA cargue una versión vieja.

## Qué subir a GitHub

Sube/reemplaza:
- app.js
- index.html
- sw.js
- README.md (opcional)
- manifest.webmanifest, style.css e icons solo si GitHub te muestra que deben
  reemplazarse; esta V30 parte de la versión visual existente.

## Supabase

La Edge Function V29 está incluida en:
supabase/functions/send-invitation/index.ts

Si V29 ya está desplegada correctamente, NO es necesario volver a desplegarla.

## Prueba

1. Ctrl+F5 en navegador.
2. Configuración → Duo/Familiar.
3. Invitar integrante.
4. Escribir el correo.
5. Enviar invitación.

El frontend no intenta comprobar invitaciones existentes antes de enviar.
