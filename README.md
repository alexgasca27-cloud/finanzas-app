# Finanzas App

Aplicación web de finanzas personales y compartidas.

## Estructura

- `index.html` — estructura de la aplicación
- `style.css` — estilos y diseño responsive
- `app.js` — lógica de frontend
- `assets/` — imágenes, logos e iconos
- `.env.example` — ejemplo de variables de entorno

## Próximos pasos

1. Publicar con GitHub Pages.
2. Crear proyecto en Supabase.
3. Conectar autenticación con Google y Apple.
4. Crear usuarios y grupos/familias.
5. Crear cuentas, tarjetas y movimientos.
6. Construir dashboard financiero.
7. Conectar un backend seguro para la IA.

> Nunca publiques API keys privadas en `app.js` ni en ningún archivo servido públicamente por GitHub Pages.
